# Customer-Churn-Prediction1
## Customer Churn Prediction using Deep Learning

## Overview
This project predicts whether a bank customer will leave the bank using an Artificial Neural Network (ANN).

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow / Keras
- Jupyter Notebook

## Dataset Features
- Credit Score
- Geography
- Gender
- Age
- Tenure
- Balance
- Number of Products
- Has Credit Card
- Is Active Member
- Estimated Salary

## Target
- Exited (0 = Stay, 1 = Leave)

## Workflow
- Data Preprocessing
- Encoding
- Feature Scaling
- Train-Test Split
- ANN Model Building
- Model Training
- Prediction
- Evaluation
